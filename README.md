# 自媒体选题监控中心 · 一体化工作台（`topic-radar-workbench`）

一套运行在本地单端口（默认 `http://127.0.0.1:18910`）的个人自媒体选题雷达与发布工作台。覆盖 **多平台博主监控 → 行业热榜垂直筛选 → 异常爆款发现 → 通义听悟转写 → MediaCrawler 热评挖掘 → AI 6 维选题推荐 → 个人选题库 6 态流转 → 视频批量发布** 完整闭环。

---

## 一、在新电脑上 3 分钟跑起来

### 1. 基础环境要求
- **Node.js 22.13+ 或 24+**（必备，内置 `node:sqlite` 数据库，无需装 MySQL/PostgreSQL/Docker）
- **Chrome 或 Edge 浏览器**（绝大多数 Windows 电脑自带，用于隔离窗口登录抖音/B站/通义听悟，绝不触碰你的日常浏览器数据）
- 可选增强：如需用「通义听悟抽音频转写」视频，请确保电脑装有 `yt-dlp` 和 `ffmpeg`；如需「MediaCrawler 抖音/B站高赞评论深采」，运行下方一键脚本即可。

### 2. 克隆并一键启动
```bash
git clone https://github.com/2392772541/topic-radar-workbench.git
cd topic-radar-workbench
```
**方式 A（Windows 最省事）**：直接双击根目录的 **`启动工作台.cmd`**，首次启动会自动安装前后端依赖、完成编译并在 `http://127.0.0.1:18910` 打开工作台。

**方式 B（命令行启动）**：
```bash
npm install --no-audit --no-fund
npm --prefix frontend install --no-audit --no-fund
npm run build
node scripts/start.mjs
```

停止工作台：双击 **`停止工作台.cmd`** 或运行 `node scripts/stop.mjs`。

### 3. 配置 AI 模型（支持任意 OpenAI 兼容接口）
二选一即可：
- **直接在页面填（推荐）**：打开工作台 → 左侧「系统设置」→ 填入接口地址（如 DeepSeek、阿里云百炼千问、智谱或本地中转站）、模型名和 API Key，点击保存即生效（内置防重复扣费缓存表 `ai_receipts`）。
- **用 `.env` 文件**：把 `.env.example` 复制为 `.env`，填入 `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` 后启动。

## 二、核心六大工作台页面

1. **选题驾驶舱**：多自媒体账号视角一键切换、核心概况 KPI、近 7 日监控与爆款趋势图、今日 TOP 智能推荐选题（6 维权重可实时拖动重算 + 5 类个性化反馈）、潜力爆款雷达、热点事件聚簇。
2. **博主监控**：支持添加/分组/管理抖音、B 站、YouTube、RSS、行业网站等监控对象，自动计算博主历史作品中位数基线，通过柱状图直观高亮相对自身常态的异常爆款。
3. **行业热榜**：免登录实时抓取 B 站全站热门、抖音实时热榜及站内高热动态，结合当前账号定位做 AI 垂直相关性筛选。
4. **话题雷达**：自定义长期追踪话题（主关键词、关联词、排除词、AI 语义关注说明、预警阈值），结合关键词规则与 AI 语义联想发现关联内容，输出 14 天趋势图与预警。
5. **内容情报库**：支持「全量情报流」与「多源事件聚簇视图」切换；展开详情可看真实互动指标（缺项明标“未提供”，绝不编造）、历史互动增长曲线、一键通义听悟转写、一键 MediaCrawler 抓热评、AI 深度拆解与历史选题查重提醒。
6. **个人选题库**：服务端持久化的 6 状态看板/列表（待研究 → 待创作 → 创作中 → 待发布 → 已发布 → 已复盘）、新建时实时历史查重、发布后真实效果复盘，并可一键带入「视频发布」页。

## 三、可选增强模块（均整合在 18910 单端口内，不多起端口）

- **通义听悟网页额度转写（已内置）**：仓库已自带 `tools/tingwu-web-batch/src/tingwu.mjs`。在「浏览器与登录」页点一次「打开通义听悟登录窗口」完成登录，即可在情报详情页一键抽音频转写口播全文。
- **抖音/B站高赞评论深采（MediaCrawler，可选）**：在新电脑上运行下面一条命令即可一键安装到 `tools/MediaCrawler/`，工作台自动识别并按需以无端口子进程调用：
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts/setup-mediacrawler.ps1
  ```
- **视频多平台批量发布（内置 `sau-engine`）**：在「视频发布」页点击「一键配置发布环境」即可完成初始化。
