# 故障排查说明

## 1. 无法打开工作台页面 (`127.0.0.1:18910`)
- 检查后台是否运行：在项目目录运行 `node scripts\start.mjs --no-open`，若提示超时请查看 `logs/workbench-YYYY-MM-DD.log`。
- 端口被其他程序占用：先运行 `停止工作台.cmd`，或设置新端口 `$env:MMW_PORT = 18920` 后再启动。

## 2. 某平台提示“需要登录”或“触发安全验证”
- 前往工作台 **「浏览器与登录」** ➔ 点击该平台 **「打开登录窗口」** 完成扫码或滑块验证。
- 关闭独立窗口后点击 **「检查状态」**，随后去 **「监控对象」** 点击 **「立即检查」**。

## 3. 点击“打开登录窗口”提示配置文件正在被占用
- 说明后台采集任务正在使用同一个平台的浏览器目录。等待几秒采集完成或前往 **「任务中心」** 取消正在执行的该平台任务即可。

## 4. 微信视频号提示“暂不支持任意外部博主”
- 受微信生态网页端权限边界限制，工作台遵循安全规范不绕过未授权接口，仅在扫码后检测账号自身授权状态。

## 5. Windows 开机自启配置
- 注册开机启动（登录即静默后台运行）：
  `powershell -NoProfile -ExecutionPolicy Bypass -File "scripts\register-autostart.ps1"`
- 卸载开机启动：
  `powershell -NoProfile -ExecutionPolicy Bypass -File "scripts\unregister-autostart.ps1"`
