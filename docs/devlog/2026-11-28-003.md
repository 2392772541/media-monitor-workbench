# 开发档案：对标博主1234归纳改造为强依赖完整口播转写的一键三步流水线

- **项目标识**：media-monitor-workbench
- **归档时间**：2026-11-28 15:43:27
- **关联提交**：4910bfd61c4779ee11c52126c8e050496a8e0bff

## 一、需求背景与目标
严禁未转写口播的视频靠标题/简介硬猜浅层要点，改为必须先经本机显卡转出完整口播逐字稿再深度提炼1234核心要点和可执行动作，并一键自动串联提音→转写→归纳全流程

## 二、现象排查与根因分析
此前未转写视频直接回退到title+summary浅层猜测且单次仅允许1条转写任务，未将显卡转写与深度归纳串行打通，且抖音优先走/playwm/慢速大文件节点及Whisper静音段存在提示词回显

## 三、方案设计与技术决策
creatorDigestService加硬性NEED_TRANSCRIPT守卫、自动清理旧浅层视频缓存、升级12000字全文覆盖与防断句深度1234提示词；tingwuBridge改为串行FIFO队列自动串联3步流水线并优化抖音优先/play/流式落盘+25秒卡顿切节点；local_asr禁用condition_on_previous_text并过滤复读幻觉；前端合并为「转写口播并归纳(1234)」一键按钮、实时展示3步进度条与绿色「基于完整口播·N字」证明标签并将概述改为上下两行铺满排版
