# 开发档案：对标博主按平台原生横竖屏展示封面并内嵌1234文案要点归纳

- **项目标识**：media-monitor-workbench
- **归档时间**：2026-11-28 14:56:43
- **关联提交**：0e41bcb3cfce10eba533cf5eac6dbfd2ecee5421

## 一、需求背景与目标
对标博主页按平台原生比例展示封面（抖音等9:16竖屏、B站等16:9横屏、无封面图文去黑框），并在卡片内针对文案简洁归纳大概讲什么、1234核心要点及1234可执行帮助

## 二、现象排查与根因分析
此前styles.css将所有视频封面强制锁死在164px 16:9小横屏导致抖音竖屏被压扁，且缺少面向单条视频文案的简洁1234要点与行动提炼视图

## 三、方案设计与技术决策
新增creatorDigestService持久化归纳接口（优先完整口播稿、无口播回退简介，自动清洗冗余编号），前端按平台区分tracker-thumb-vertical(126x224 9:16)/tracker-thumb-horizontal(248x139.5 16:9)/none，并在卡片内嵌无嵌套边框的1234双栏归纳区与一键批量归纳

## 四、核心实现与变更范围
- `frontend/src/pages/CreatorsPage.tsx`
- `frontend/src/styles.css`
- `src/api/radarRoutes.ts`
- `src/services/creatorDigestService.ts`
- `tests/creator-digest.test.mjs`

## 五、测试验证与客观证据
测试命令: `npm run build && npm test && node verify_digest_api.mjs && real-browser E2E on http://127.0.0.1:18910/#creators`


## 六、踩坑记录与问题沉淀
重启18910服务前仅按PID精准停止旧node dist/server.js，避免@fastify/static缓存旧前端构建产物；竖屏卡片将1234归纳置于封面右侧对齐高度以消除留白
