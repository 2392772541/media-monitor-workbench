# 开发档案：补充抖音扫码实时状态提示并停用隐藏桌面旧进程

- **项目标识**：media-monitor-workbench
- **归档时间**：2026-11-26 09:56:29
- **关联提交**：75366802f070d3cc92a947692383e023433b9b65

## 一、需求背景与目标
解决工作台运行在隐藏桌面导致扫码浏览器弹窗不可见，同时补充抖音扫码后状态和验证提示

## 二、现象排查与根因分析
18910 工作台此前由后台隔离终端拉起，运行于隐藏桌面(exebox)，导致其派生的有界面 Chrome 弹窗用户不可见；且原循环未回传扫码后验证状态提示

## 三、方案设计与技术决策
在抖音登录轮询中增加 URL 变化日志与已扫码/安全验证实时状态推送；通过 stop.mjs 安全停掉隐藏桌面旧实例，改由用户双击 启动工作台.cmd 在真实桌面拉起

## 四、核心实现与变更范围
- `sau-engine/uploader/douyin_uploader/main.py`

## 五、测试验证与客观证据
测试命令: `py_compile && pytest -q && node scripts/stop.mjs`
结果:
```text
34条单测通过，隐藏桌面旧实例已安全退出
```

## 六、踩坑记录与问题沉淀
Windows 下由隔离桌面拉起的守护服务无法把 GUI 窗口弹到用户主桌面，涉及可见浏览器的本地工具必须由用户从真实桌面启动
