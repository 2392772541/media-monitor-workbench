# 开发档案：今日速览爆款墙改按博主轮询排位防单人霸屏并加平台快筛与展开全部

- **项目标识**：media-monitor-workbench
- **归档时间**：2026-11-26 10:49:34
- **关联提交**：fd5ab96073da9b344ca2a2df12a12a1a4238021a

## 一、需求背景与目标
解决今日速览对标博主爆款墙全部被单个博主(影视飓风)霸占的问题

## 二、现象排查与根因分析
原接口仅按breakout_ratio纯降序截前4条，高倍博主直接挤掉水球泡等其他博主的爆款

## 三、方案设计与技术决策
后端按source_id分组轮询排位(每轮各取每博主1条最爆作品)，前端增加全部/抖音/B站快筛胶囊与展开全部开关，抖音卡底部补充点赞+收藏展示

## 四、核心实现与变更范围
- `frontend/src/pages/CockpitPage.tsx`
- `frontend/src/types.ts`
- `src/api/radarRoutes.ts`

## 五、测试验证与客观证据
测试命令: `npm run build && npm test && browser check on 18910/#overview`
结果:
```text
编译与8/8单测通过，首屏4张卡按影视飓风/水球泡交替展示且可切平台/展开全部
```

## 六、踩坑记录与问题沉淀
多平台博主混排时需同时做轮询去霸屏与平台筛选，避免倍数尺度差异导致单一博主霸屏
