# 开发档案：对标博主极简重构 V4：实时追更提醒（不翻老视频）+ 按博主分类 + 内联一键拿口播文案

- **项目标识**：media-monitor-workbench
- **归档时间**：2026-11-28 11:58:30
- **关联提交**：3b38063049ca7526a3728a67276ff40c2a5503aa

## 一、需求背景与目标
精简对标博主页面，彻底去掉复杂图表与杂乱排行，仅保留三件事：1.实时追查新更新并第一时间提醒，默认不堆老视频;2.按博主分类点谁看谁;3.视频卡片内直接一键获取/展开/复制博主完整口播文案

## 二、现象排查与根因分析
此前对标博主页混入了排行榜、走势图与大量历史视频，偏离了追更与拿文案的高频核心诉求；另外 .tracker-thumb 缺少 position:relative 导致无封面 RSS 条目占位层全屏拦截点击

## 三、方案设计与技术决策
后端新增 /api/radar/creators/feed(默认近7天+未读计数+实时追更状态)、/check-all、/mark-read、/interval(默认30分钟)并在首次建档时将7天前历史视频自动标为已读；前端重构为极简双栏追更台并支持原位展开3827字完整口播文案与一键复制
